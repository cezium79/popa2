## Как тестировать
1. Открыть настройки → Маршруты
2. Нажать на кнопку "Редактировать свойства чекпоинтов"
3. В новом окне увидеть список всех чекпоинтов
4. Нажать на любой чекпоинт для выбора картинки из галереи
5. Вернуться назад, картинки будут сохранены
6. При сканировании QR-кода с `action: "photo"` будет показана привязанная картинка
