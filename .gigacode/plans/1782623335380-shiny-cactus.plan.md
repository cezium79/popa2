## Как использовать новую систему

### 1. Создание чекпоинта
1. Откройте "Настройки" → "Маршруты"
2. Нажмите кнопку "Создать новый чекпоинт" (в разделе 3)
3. Заполните поля:
   - **ID чекпоинта** - уникальный идентификатор (например, CP-001)
   - **Имя чекпоинта** - отображаемое имя (например, "Точка входа")
   - **Тип действия** - выберите один из:
     - `checkpoint` - простой чекпоинт
     - `question` - чекпоинт с вопросом
     - `input` - чекпоинт с вводом данных
     - `photo` - чекпоинт с фото

### 2. Работа с типами чекпоинтов

#### Тип: question
Дополнительные поля:
- **Текст вопроса** - вопрос, который будет показан при сканировании
- **Ответы** - список ответов, которые можно выбрать (можно добавлять/удалять)

#### Тип: input
Дополнительные поля:
- **Текст запроса** - название поля для ввода данных

#### Тип: photo
Дополнительные поля:
- **Картинка прибора** - привязанная картинка, которая будет показана при сканировании

### 3. Редактирование чекпоинта
- В списке чекпоинтов нажмите кнопку "Редактировать" (иконка карандаша)
- Измените любые поля
- Нажмите кнопку "Сохранить" в верхней панели

### 4. Удаление чекпоинта
- В списке чекпоинтов нажмите кнопку "Удалить" (иконка корзины)

### 5. Сканирование QR-кодов
Когда администратор создает QR-код для чекпоинта, он должен использовать **только ID** чекпоинта. Приложение при сканировании будет:
1. Брать ID из QR-кода
2. Искать чекпоинт в базе данных по этому ID
3. Брать все данные ( имя, тип, вопрос, ответы, картинка) из базы
4. Отображать соответствующий экран (вопрос, ввод данных, фото) на основе типа

### Пример QR-кодов

Для простого чекпоинта:
```json
{
    "id": "CP-001",
    "name": "Точка входа",
    "type": "checkpoint"
}
```

Для чекпоинта с вопросом:
```json
{
    "id": "CP-002",
    "name": "Точка контроля",
    "type": "checkpoint",
    "action": "question",
    "text": "Какое состояние двери?",
    "answers": ["Закрыта", "Открыта", "Повреждена"]
}
```

Для чекпоинта с вводом данных:
```json
{
    "id": "CP-003",
    "name": "Показания прибора",
    "type": "checkpoint",
    "action": "input",
    "title": "Введите показания счетчика"
}
```

Для чекпоинта с фото:
```json
{
    "id": "CP-004",
    "name": "Прибор 1",
    "type": "checkpoint",
    "action": "photo"
}
```

## Преимущества новой архитектуры
1. **Единственный источник истины** - все данные чекпоинтов хранятся в базе
2. **Удобное редактирование** - не нужно перегенерировать QR-коды при изменении данных
3. **Централизованное управление** - администратор управляет всеми данными через один экран
4. **Гибкость** - можно добавлять новые типы действий без изменения структуры
5. **Сохранение картинок** - привязанные картинки сохраняются вместе с чекпоинтом

## Как использовать систему расписания обходов

### 1. Открытие ScheduleScreen
1. Откройте "Настройки" → "Маршруты"
2. Нажмите кнопку "Расписание обходов"

### 2. Настройка количества обходов (Раздел 1)
- Используйте кнопки "+" и "-" для изменения количества обходов
- Количество обходов автоматически синхронизируется с количеством полей времени

### 3. Настройка времени обходов (Раздел 2)
- Введите время для каждого обхода в формате HH:MM
- Используйте переключатели "Вкл/Выкл" для активации/деактивации будильников

### 4. Настройка допуска и длительности (Раздел 3 и 4)
- **Допуск времени (мин)** - насколько рано можно начать обход (по умолчанию 15 минут)
- **Макс. длительность обхода (мин)** - максимально допустимое время обхода (по умолчанию 30 минут)

### 5. Сохранение настроек
- Нажмите кнопку "Сохранить" в разделе 4
- Все настройки сохраняются в SharedPreferences и не теряются при перезапуске

### 6. Подтверждение сохранения
- После сохранения появится диалог "Данные сохранены!"
